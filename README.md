# 鸭 还是 鹅 · 火眼金睛大对决 🦆🆚🦢

**科普小游戏**——很多人其实根本分不清鸭和鹅，那就来一场边玩边学的辨别大挑战。

👉 **在线试玩**：开启 GitHub Pages 后见仓库 Settings → Pages 链接。

## 玩法

- **🍗 熟食辨腿 · 剧情**：替「鹅腿摊主」把关，4 夜剧情闯关，识破用鸭腿冒充鹅腿的对手。
- **🦆 活体识鸟 · 科普**：从雏鸟到成年，**同年龄段对比**认清活鸭与活鹅（破壳辨雏 → 成年初阵 → 成年决战）。
- **⚔️ 校际对决 · PK**：代表自定义战队守擂，7 题限时抢答 vs 对手战队，赢取战力、登上校际战力榜。
- **📖 鸭鹅图鉴**：认对即解锁物种卡，系统讲清鸭与鹅在外形 / 价格 / 习性上的差异。

战力值、段位、连胜、图鉴进度、校际积分均保存在浏览器本地（localStorage）。

## 核心辨别口诀

| 维度 | 鹅 | 鸭 |
|---|---|---|
| 脖子 | 长（最好认） | 短 |
| 体型 | 大一圈 | 小巧 |
| 喙 | 尖、根部高 | 宽扁如勺 |
| 价格 | 鹅腿约 15–20 元 | 鸭腿约 8–12 元 |

## 运行

纯静态单页，无需构建。直接用浏览器打开 `index.html` 即可；或本地起服务：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```
